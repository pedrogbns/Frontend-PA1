Arquitetura Cliente-Servidor

Análise do acesso ao site portal.fgv.br

Fluxo de comunicação cliente-servidor

Quando um usuário digita portal.fgv.br no navegador, inicia-se um processo de comunicação entre o cliente, que neste caso é o navegador, e o servidor responsável pelo site.

Primeiro, o navegador precisa descobrir o endereço IP associado ao domínio portal.fgv.br por meio do DNS. Depois disso, a requisição percorre a Internet através de diferentes roteadores até chegar ao servidor. O servidor processa a solicitação e envia uma resposta de volta ao navegador, que interpreta os arquivos recebidos e apresenta a página ao usuário.

Resolução DNS

O DNS (Domain Name System) é responsável por traduzir nomes de domínio, como portal.fgv.br, em endereços IP que permitem localizar servidores na Internet.

Quando o usuário acessa o site, o navegador verifica se já possui o endereço IP armazenado em cache. Caso não tenha, realiza uma consulta ao sistema DNS para descobrir o endereço correspondente. Com o endereço IP obtido, o navegador pode estabelecer uma conexão com o servidor do site.

Cache do navegador

O cache do navegador é um mecanismo que armazena temporariamente recursos de sites visitados, como imagens, arquivos CSS e JavaScript.

Quando o usuário acessa novamente o portal.fgv.br, o navegador verifica se possui recursos armazenados em cache e se eles ainda podem ser reutilizados. Isso pode reduzir a quantidade de dados transferidos do servidor, tornando o carregamento da página mais rápido.

O papel dos roteadores

Os roteadores são dispositivos responsáveis por encaminhar pacotes de dados entre diferentes redes, permitindo a comunicação entre o cliente e o servidor.

Quando o usuário acessa o portal.fgv.br, os dados enviados pelo navegador são divididos em pacotes que percorrem diferentes roteadores pela Internet até chegar ao destino.

Cada roteador analisa o endereço IP de destino e utiliza sua tabela de roteamento para determinar o próximo caminho dos pacotes. As respostas do servidor também percorrem a rede até chegar ao navegador do usuário.

Diferença entre frontend e backend

Frontend

O frontend é a parte da aplicação com a qual o usuário interage diretamente. É responsável pela apresentação visual, organização dos conteúdos e interatividade da página.

No portal.fgv.br, o navegador interpreta o HTML, CSS e JavaScript para apresentar os elementos da página, como textos, imagens, menus e botões.

Backend

O backend é a parte da aplicação executada no servidor. É responsável por processar requisições, executar regras de negócio e, quando necessário, acessar bancos de dados.

No contexto do portal.fgv.br, o backend pode processar solicitações do navegador, consultar informações e enviar respostas para que o frontend apresente os dados ao usuário.
